# SI728 - Final Project Report Template

Estructura de archivos Markdown organizada a partir del **Final Project Statement de SI728 - Arquitecturas de Software Emergentes**.

La organización sigue el estilo mostrado en el repositorio de referencia: archivos generales en la raíz y un archivo por capítulo dentro de `chapters/`.

> Los archivos contienen **qué exige el Statement en cada sección**. Durante el desarrollo del proyecto, reemplacen o complementen estas instrucciones con el contenido real de su startup/producto.

## Estructura

```text
Report/
├── README.md
├── cover.md
├── versions.md
├── content.md
├── outcome.md
└── chapters/
    ├── chapter1.md
    ├── chapter2.md
    ├── chapter3.md
    ├── chapter4.md
    ├── chapter5.md
    ├── chapter6.md
    ├── chapter7.md
    └── conclusions.md
```

## Orden recomendado del informe

1. `cover.md`
2. `versions.md`
3. `content.md`
4. `outcome.md`
5. `chapters/chapter1.md`
6. `chapters/chapter2.md`
7. `chapters/chapter3.md`
8. `chapters/chapter4.md`
9. `chapters/chapter5.md`
10. `chapters/chapter6.md`
11. `chapters/chapter7.md`
12. `chapters/conclusions.md`

## Importante

El Statement oficial contiene **7 capítulos**, por lo que esta plantilla no incluye `chapter8.md`.
